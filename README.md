# Head Trauma Front Office

Head Trauma Front Office is a personal, non-commercial fantasy football analysis project.

The application uses read-only access to my Yahoo Fantasy Football league data to assist with:

- Roster analysis
- Waiver and free-agent decisions
- Lineup decisions
- Trade analysis
- Matchup analysis
- Keeper strategy

The application is intended for a single user and does not submit transactions or modify Yahoo Fantasy rosters.

Yahoo Fantasy data is accessed through the official Yahoo Fantasy Sports API.
